# Showcase Image Credits

Every photograph in `public/showcase/` is a **real-world photo** (no AI-generated
art) sourced from Wikimedia Commons under a Creative Commons license, per the
project owner's instruction. This file records the attribution each license
requires (CC BY / CC BY-SA require creator attribution; linking the source page
here satisfies it for a site-wide credits file).

Used on the landing page: the hero photo collage (`hero-main`, `hero-dj`,
`hero-stage`) and the five-tile showcase moodboard (`food-festival`,
`culture-day`, `football-night`, `sunday-gospel`, plus `hero-stage`).

Notes for future image swaps:

- Keep licenses to CC0 / Public Domain / CC BY / CC BY-SA. Avoid NC/ND variants
  (they restrict commercial use or edits) and avoid "Fair use" files entirely.
- Event cards and detail pages render **organizer-supplied** media; this credit
  file covers only the platform's own showcase photography.
- If a slot is replaced, update this table in the same commit.
